# Emoji Memory Game

A simple emoji-based memory matching game originally built around 2021
and revisited as a standalone demo.

## Features
- Emoji matching logic
- Animated gradient background
- Resettable game state
- Pure JavaScript (no frameworks)

## Tech
- HTML
- CSS
- Vanilla JavaScript

## Running Locally
Open `index.html` in a browser, or use a local server if preferred.

## Notes
This project focuses on game logic and DOM interaction rather than
framework usage.
